# AI Tools Lab

## Project Description

AI Tools Lab is a Python project created for learning and practicing programming concepts with the help of AI tools. The project contains sorting algorithms and useful utility functions implemented in Python.

## Features

- Sorting algorithms
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion
- AI-assisted development and documentation
